# Project Rules

- Use one editorial, monochrome layout system with violet accents across pages, while giving each section a distinct composition so the portfolio never reads as a grid of repeated cards.
- Mark genuine content cards with `border-glow-card`; keep pills, icon holders, controls, and media frames unmarked so the interaction stays restrained.
- Use an editorial-noir hierarchy: Instrument Serif display type, Work Sans body copy, wide-tracked metadata, square-leaning controls, and generous negative space; avoid adding decorative containers.
