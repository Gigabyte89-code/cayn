# Jacopo Digital Craft

Create a highly polished, premium, modern personal portfolio website for a young developer and digital creator named Jacopo.

The website must feel like a blend between Apple's design language, modern startup landing pages, futuristic SaaS websites, and high-end creative developer portfolios.

The overall experience should immediately communicate innovation, professionalism, creativity, technical skills, and attention to detail.

General Design Direction

The website must be visually stunning and memorable.

Use:

Full dark theme Deep black background (#000000) Glassmorphism everywhere Liquid glass effects Frosted glass cards Dynamic reflections Subtle transparency Blur effects Premium shadows Modern gradients Soft glow accents Floating UI elements Layered depth

The website should feel futuristic and immersive.

Every section should feel alive through motion and depth.

The visual style should resemble:

Apple Vision Pro marketing pages Modern Vercel-inspired websites Premium Framer portfolio templates Luxury SaaS landing pages Creative developer portfolios from Awwwards

Avoid looking like a generic portfolio template.

The website must feel custom designed.

Animations

Include advanced animations throughout the website.

Examples:

Smooth page transitions Scroll-triggered animations Floating glass panels Hover effects 3D card interactions Mouse-following effects Depth-based parallax Dynamic lighting effects Smooth fade-ins Scale animations Magnetic buttons Animated gradients Floating particles

All animations should feel premium and smooth.

No cheap or excessive animations.

The website should maintain excellent performance.

3D Elements

Use modern 3D design throughout the website.

Include:

Floating 3D geometric objects Abstract glass spheres Transparent floating cubes Liquid glass blobs Dynamic 3D backgrounds Depth effects Interactive 3D elements reacting to cursor movement

The 3D elements should create a sense of innovation and modernity.
